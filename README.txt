ขั้นตอนอัปโหลด
1) Apps Script: วาง Code.gs ทับของเดิม (ลบ Index.html และ Logo.html ในโปรเจกต์ได้) → รันฟังก์ชัน setup 1 ครั้ง
   → ไปที่ชีตแท็บ "แอดมิน" พิมพ์รหัสแอดมินที่เซลล์ A2 (ใส่ A3, A4 ต่อเพื่อมีหลายรหัสได้)
   → Deploy > Manage deployments > Edit > New version
2) Web app: Execute as = Me, Who has access = Anyone
3) GitHub: สร้าง repo แล้วอัปโหลดไฟล์เหล่านี้ทั้งหมดไว้ที่ราก (root) ของ repo
      index.html
      manifest.webmanifest
      sw.js
      icon.svg
      icon-192.png
      icon-512.png
      icon-maskable-512.png
      apple-touch-icon.png
   แล้ว Settings > Pages > Deploy from branch (main, /root)
4) ลิงก์แจกนักเรียน: https://ชื่อคุณ.github.io/ชื่อrepo/?openExternalBrowser=1

การติดตั้งแอป (PWA)
- ต้องเปิดผ่าน https (GitHub Pages ใช้ได้เลย) และอัปโหลดไฟล์ข้างบนครบทุกไฟล์
- ปุ่มติดตั้ง (ไอคอนลูกศรลง) อยู่ที่หัวเว็บ ข้างปุ่มฟันเฟือง · เปิดจากไอคอนบนหน้าจอหลักแล้วปุ่มจะหายไปเอง
- Android/Chrome: กดปุ่มแล้วขึ้นหน้าต่างติดตั้งทันที (และมีแถบชวนติดตั้งขึ้นเองครั้งแรก ปิดแล้วไม่ขึ้นอีก 7 วัน)
- iPhone/iPad: ต้องติดตั้งจาก Safari เท่านั้น กดปุ่มแล้วมีขั้นตอนบอก (แชร์ > เพิ่มไปยังหน้าจอโฮม)
- เปิดจากในแอป LINE/Facebook ติดตั้งไม่ได้ ปุ่มจะบอกให้เปิดในเบราว์เซอร์ก่อน (ลิงก์ ?openExternalBrowser=1 ช่วยเรื่องนี้)
- อัปเดตเว็บ: แค่อัปโหลด index.html ใหม่ ผู้ใช้จะได้ของใหม่เองตอนเปิดแอปครั้งถัดไป
  (ถ้าแก้ไฟล์ไอคอน/manifest แล้วไม่เปลี่ยน ให้แก้เลข VERSION ใน sw.js)

ลีกละ 10 คน
- ตั้งค่า LEAGUE_CAP = 10 ทั้งใน Code.gs และ index.html (ต้องตรงกัน)
- แอดมินลบสมาชิก → คนที่เข้าก่อนสุดของลีกถัดไปจะเลื่อนมาเติมลีกที่ขาด แล้วไล่ต่อกันไปทุกลีก
- ครั้งแรกหลังเปลี่ยนจาก 20 เป็น 10: รันฟังก์ชัน rebalanceLeagues 1 ครั้งใน Apps Script เพื่อย้ายคนส่วนเกินของแต่ละลีก

UCL รอบแบ่งกลุ่ม
- UCL ใหม่ทุกฤดูกาลเริ่มด้วยรอบแบ่งกลุ่ม (กลุ่มละ 4 ทีม จับสลากตามโถ) แล้วที่ 1-2 เข้ารอบแพ้คัดออก
- ตั้งค่าที่ CONFIG: UCL_GROUP_SIZE, UCL_GROUP_ADVANCE, UCL_LEGS (2 = เหย้า-เยือน 6 นัด / 1 = เที่ยวเดียว 3 นัด)
- แท็บ UCL ในชีตมีคอลัมน์ "กลุ่ม" เพิ่ม (ระบบเติมหัวคอลัมน์ให้เอง) · UCL ที่กำลังแข่งอยู่ก่อนอัปเดตจะแข่งแบบเดิมจนจบ

จัดลีกใหม่
- หน้าแอดมินมีปุ่ม "จัดลีกใหม่" (หรือรันฟังก์ชัน repackLeagues ใน Apps Script) เรียงทุกคนตามลำดับสมัคร แล้วแบ่งลีกละ 10 คนใหม่ · ทำไม่ได้ตอน UCL กำลังแข่ง
- ตอนจัดลีกใหม่ ผลในแท็บ "ผลแข่งขัน" จะถูกย้ายไปต่อท้ายแท็บ "ผลแข่งขัน (เก่า)" แล้วเริ่มบันทึกใหม่ (เลขรอบนับต่อ) · แท็บ UCL ไม่ถูกแตะ

บังคับอัปโหลดรูป + กันแก้การ์ดคนอื่น (อัปเดตล่าสุด)
- บันทึกการ์ดเป็น 2 จังหวะ: เซิร์ฟเวอร์สุ่มค่าพลัง/ทีมแล้ว "พักไว้" ก่อน (CONFIG.PENDING_MINUTES = 30 นาที) แถวในชีตจะถูกสร้างต่อเมื่อรูปการ์ดมาถึงและผ่านการตรวจ (เป็น PNG จริง สัดส่วนถูก ไม่ใช่ไฟล์จิ๋ว/ภาพว่าง) → ไม่มีแถวที่ไม่มีรูปอีก
- ชีต Cards มีคอลัมน์ใหม่ 2 คอลัมน์ (รหัสเจ้าของ(แฮช), สุ่มทีมใหม่(ครั้ง)) ระบบเติมหัวคอลัมน์ให้เองตอนรัน setup หรือเมื่อมีคนบันทึกครั้งแรกหลังอัปเดต · อย่าลบ/ย้ายคอลัมน์ Q-S
- สุ่มทีมใหม่ได้กี่ครั้งตั้งที่ CONFIG.REROLL_MAX (ค่าเริ่มต้น 1) เซิร์ฟเวอร์นับเอง
- การ์ดเก่าที่สร้างก่อนอัปเดตไม่มีรหัสเจ้าของ → นักเรียนแก้ผ่านเว็บไม่ได้ ให้แอดมินแก้ในหน้าแอดมิน
- ครั้งแรกหลังอัปเดต: รัน setup 1 ครั้ง แล้วรัน listImagelessCards เพื่อดูแถวเก่าที่ไม่มีรูป และ purgeImagelessCards เพื่อลบ (หรือใช้เมนู ⚽ ระบบการ์ด ในชีต) · จากนั้น Deploy > Manage deployments > Edit > New version
- CARD_PNG_MIN_BYTES (ค่าเริ่มต้น 15000) ปรับได้ถ้ารูปการ์ดจริงของคุณเล็ก/ใหญ่กว่านี้มาก

ล็อกอินด้วย Gmail (บังคับก่อนบันทึกการ์ด · 1 บัญชีสร้างได้ไม่จำกัดใบ)
- สร้าง OAuth Client ID: Google Cloud Console > APIs & Services > Credentials > Create credentials > OAuth client ID > Web application
  · Authorized JavaScript origins ใส่ https://ชื่อคุณ.github.io (ไม่ต้องใส่ path) · ต้องตั้งหน้า OAuth consent screen ก่อน (ถ้ายังไม่เคย)
- วาง Client ID เดียวกันใน 2 ที่: GOOGLE_CLIENT_ID ใน Code.gs (CONFIG) และ GOOGLE_CLIENT_ID ใน index.html
- จำกัดเฉพาะอีเมลโรงเรียนได้ที่ CONFIG.GOOGLE_ALLOWED_DOMAIN (เว้นว่าง = Gmail ใดก็ได้)
- Code.gs ใช้ UrlFetchApp ตรวจโทเค็นกับ Google → ต้องรันฟังก์ชัน setup 1 ครั้งเพื่ออนุญาตสิทธิ์ใหม่ แล้ว Deploy > Manage deployments > Edit > New version
- ระบบเก็บเฉพาะแฮชของรหัสบัญชี Google ไว้เป็นเจ้าของการ์ด (คอลัมน์ รหัสเจ้าของ(แฮช)) ไม่เก็บอีเมลลงชีต · ล็อกอินค้างได้ไม่เกิน 6 ชั่วโมง
- การ์ดเก่าที่สร้างก่อนเพิ่มระบบนี้ เจ้าของแก้ผ่านเว็บไม่ได้ ให้แอดมินแก้ในหน้าแอดมิน
- เปิดจากแอป LINE/Facebook ล็อกอิน Google ไม่ได้ ใช้ลิงก์ที่มี ?openExternalBrowser=1

เก็บอีเมลเจ้าของการ์ดลงชีต (อัปเดตล่าสุด)
- ชีต Cards มีคอลัมน์ใหม่ T "อีเมลเจ้าของ" (ระบบเติมหัวคอลัมน์ให้เอง) · ใส่อีเมลตอนบันทึกการ์ด และอัปเดตทุกครั้งที่เจ้าของบันทึกซ้ำ
- การ์ดที่สร้างก่อนอัปเดตจะไม่มีอีเมล (ระบบไม่เคยเก็บไว้ และการ์ดเก่าไม่มีรหัสเจ้าของให้ผูกย้อนหลัง) ช่องนั้นจะว่าง
- หน้าแอดมิน: ค้นหาด้วยอีเมลได้ และชี้ที่ชื่อสมาชิกเพื่อดูอีเมล
- อีเมลเป็นข้อมูลส่วนบุคคล ควรแจ้งนักเรียนว่าเก็บไว้เพื่ออะไร และจำกัดคนที่เข้าถึงชีต (Share) ให้เฉพาะผู้ดูแล
- ครั้งแรกหลังอัปเดต: วาง Code.gs ทับ → รัน setup 1 ครั้ง → Deploy > Manage deployments > Edit > New version · แล้วอัปโหลด index.html ใหม่ขึ้น GitHub
