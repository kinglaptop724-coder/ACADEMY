ขั้นตอนอัปโหลด
1) Apps Script: วาง Code.gs ทับของเดิม (ลบ Index.html และ Logo.html ในโปรเจกต์ได้) แล้ว Deploy > Manage deployments > Edit > New version
2) Web app: Execute as = Me, Who has access = Anyone
3) GitHub: สร้าง repo อัปโหลด index.html > Settings > Pages > Deploy from branch (main, /root)
4) ลิงก์แจกนักเรียน: https://ชื่อคุณ.github.io/ชื่อrepo/?openExternalBrowser=1
